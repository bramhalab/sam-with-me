# ✂️ My SAM Studio

Personal "Segment Anything" studio built on Meta's **SAM 3**.

- Image + video
- Select many objects: text prompts (AI) and/or clicks
- A different effect per object (blur, glow, thermal, cartoon, glitch, inpaint, custom code ...)
- Export: effects video, green-screen cut-out, black/white mask

Setup for Hugging Face + GitHub Actions, Colab and Kaggle: see `SETUP.md`.
